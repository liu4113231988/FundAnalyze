# fund-index-lens · 主动基金指数拟合与趋势估值研究

把一只主动基金用 **滚动 RBSA（基于收益的风格分析）** 还原成「指数 + 风格因子」的组合，
再基于合成基准的趋势与估值状态生成仓位建议，并对整套逻辑做**严格样本外回测与对照实验**。

> 核心发现见 [`docs/研究方案.md`](docs/研究方案.md) 与 [`report/回测报告.html`](report/回测报告.html)。
> 一句话：**风格穿透确定成立；日频择时被证伪；把周期拉到年线后出现正贡献。**

> ## ⚠️ 结论口径已于 2026-10-12 修正并重算（P0-01 / P0-03 / P0-06 / P2-02）
>
> **1. 收益口径（P0-01，已核实并修正）**
> 旧口径（数据源「累计净值走势」直算）在 14 只基金上**平均低估 23.19%**，
> 最严重的 110013 低估 **76.12%**。原因是累计净值 = 单位净值 + 历史累计分红，
> 而累计分红是存量、不参与后续增长，每期收益都被乘上一个 `U/C < 1` 的压缩因子，
> 且分红越多压缩越狠、随时间加重。
> 现默认改用**日频总回报**（累计净值 + 单位净值 + 月频累计收益率校准，
> 14/14 只基金与真值偏差 **0.0000%**）。
>
> **2. 功效分析（P0-06，已重做）** —— 旧的"约 190 只基金即可显著"已撤回。
> 按 α=0.05 双侧、目标功效 80%、δ=|mean(IR)|/sd(IR) 重算，分策略给出所需基金数：
> 健康门控 **554 只**（δ 仅 0.149，当前功效 **6.5%**）、
> 波动率目标 **89 只**（当前功效 19.8%）、
> E4 低频 **26 只**（当前功效 55.2%，但其 δ=1.30 来自 12 格网格的最优格子，
> 被选择偏差抬高，只能当乐观下界）。
>
> **3. 时间向前验证（P0-03 / E9b，新增）**
> 横截面（按管理人分折）迁移 IR **+0.300**（10 年窗口下为 +0.341）；
> 但**时间维度**迁移 IR **−0.672**、过拟合代价 +1.547
> （10 年窗口下为 −0.23 / +0.769）。
> **E9 的横截面结论不得外推为时间泛化**，且缩短窗口后差距进一步拉大。
> 注意别把"过拟合代价"读成"参数选择过拟合"：P1-03 的选择感知检验拆解后，
> 近 5 年窗口下 **66% 来自"从 12 个候选里挑最大值"的抽签运气、34% 是真实过拟合**
> （10 年窗口下运气占 115%、真实过拟合 −15%，即训练期选择相对平均水平甚至略好）。
> 真正的问题是**整个候选集在测试期的 IR 均值为负**，不是选参选错了。
>
> **4. 多重比较校正后三条策略全部不显著**
> 健康门控 p=0.432、波动率目标 p=0.291、E4 低频 p=0.189；
> BH-FDR 与 Bonferroni 均无一项通过。此处的不显著更可能是**缺乏功效**
> （当前功效 6.5%~55.2%），而非"有效应不存在"——这两件事必须分开陈述。
>
> **5. 朴素基准对照（P2-02，已做事前公平比较）**
> 「最优单一宽基」那种**事后**挑候选的比较对受约束回归不公平（前者占了选择偏差）。
> 改成"选哪个宽基也只在训练段完成"之后，结论更明确：
> 受约束回归样本外 R² 均值 **0.688**，仍**低于**单一宽基的 **0.738**
> （增量 −0.05，仅 **3/14** 只基金增量 > 0.05）。
> **风格画像在解释力上并不优于"挑一个宽基"** —— R² 高低主要来自指数数量而非解释力。
> 但它有一个真实优势：**权重稳定性**（相邻训练段 L1 = 0.86 vs 1.64），
> 说明多出来的指数确实在刻画一个持续的结构，而不是多拟合了噪声。
> → 风格画像的价值在**稳定性与可解释性**，不在拟合优度。据此**不建议**以
> "提高 R²"为目标扩池（P2-01）。
>
> 修正前的数字归档见 [`docs/结论快照_口径修正前.md`](docs/结论快照_口径修正前.md)，
> 重算后的逐条对比见同文件「重算结果与翻转项」节；增量分析见
> `run_increment.py` → `output/results/P2-02_增量价值分析.csv`。
>
> **6. 分析窗口：已从固定 2016 起（约 10 年）改为滚动近 5 年（2026-10-13）**
> 十年跨度里风格漂移、经理变更、市场制度变化会把性质不同的样本混在一起，
> 拟合出的"风格画像"是十年平均，对当下没有指导意义。下限 **2 年**：
> 再短的话拟合窗口（252 日）与预热会吃掉大部分数据。
> E0–E9 已按近 5 年重算（产物在 `output/results/`，10 年窗口的旧值快照在
> `output/results_10年窗口_修正前/`）；`docs/研究方案.md` 正文表格多为旧口径，
> 逐节重写未完成，关键翻转项见 [`TODO.md`](TODO.md) §四「第五轮」。
> 新增**风格漂移检测**：经理变更数据取不到（免费源只有现任、无任职日期），
> 改为直接检测拟合权重的结构是否漂移。见 `docs/研究方案.md` §4c。
>
> **7. 真实持仓的外部验证 + 扩池（2026-10-13，新增）**
> RBSA 的权重此前只有**内部**检验（自洽性），没有外部证据。
> 现接入季报/半年报持仓明细做直接对比（`python run_holdings.py --pool`）。
> **扩池按预注册规则从 14 只扩到 60 只**（三层各 20、单管理人 ≤3、剔除行业基金、
> 排除 25414 条留痕），结果**推翻了一条基于 14 只的结论**：
> 人工样本下"RBSA 与真实持仓的一致性系统性下降（−0.175）"，
> 规则抽样下只剩 **−0.047**、33 降 / 27 升 —— **没有系统性**。
> 更直接的是首期相关从 0.887 掉到 **0.594**：人工挑的 14 只本身就更容易被拟合，
> 正是预注册规则警告的"选择偏差"，实测证实。
> 稳健成立的是：平均绝对偏差 **0.102**（精度约 10%，两个样本一致）、
> 持仓基准 vs RBSA **接近平手**（53% 持仓更优）→ RBSA 的价值在连续性而非精度。
> 限制：季报只有前十大，故**只做半年度对齐**；持仓有披露滞后；**存续偏差未消除**
> （无免费清盘基金清单）。详见 `docs/研究方案.md` §4d。

## 🖥 Web 界面（交互式分析台）

输入任意 6 位基金代码，网页会给出：净值走势、与候选指数池的相关性分析
（定义 47 个，按覆盖率过滤后通常剩 40~44 个）、
**十一种机器学习方法的拟合结果横向对比**，并自动选出样本外表现最好的那个。

```bash
pip install -r requirements.txt
python webapp/serve.py --restart        # 启动后浏览器打开 http://127.0.0.1:8760
```

浏览器里可以：

| 功能 | 说明 |
|---|---|
| **净值走势** | 累计净值、回撤、60 日滚动波动、月度收益热力图 |
| **相关性分析** | Top15 排行榜、四层大类平均相关、16×16 相关性矩阵、滚动相关演化（看风格漂移） |
| **多模型横向对比** | 同一份数据切分上滚动样本外评估，按样本外 R² 排名 |
| **模型详情** | 拟合曲线、残差、权重时间演化、当前权重条形图 |
| **风格漂移** | 拟合权重的结构突变、前后半持仓对比、分年度画像（见 `docs/研究方案.md` §4c） |
| **超参调节 + 重新学习** | 改任意超参点"重新学习"，结果就地替换并自动重算最佳模型 |
| **手动选优** | 点任意模型卡或表格行查看详情，点"设为最佳模型"锁定基准 |

**分析窗口**：右上角可切换「近 2 / 3 / 5 / 10 年」，默认 **5 年**、下限 **2 年**
（再短则拟合窗口与预热会吃掉大部分数据）。换窗口后需重新分析，否则其余区块
仍停在旧窗口上；回测区间若未手动改过会跟随窗口自动更新。

**速度控制**：右上角可切换「快速模式 5 个模型 / 全部 11 个模型」与「重估点 30/60/100/全部」。
默认 5 模型 + 60 重估点约 **20~40 秒**；结果按 (基金, 模型集, 参数, 精度, 分析窗口) 落盘缓存，重开秒回。

**指标解释**：全页 60 个指标标签都带下划线与 `?` 图标，悬停弹出「是什么 / 怎么算 / 怎么看」
三段说明；「怎么看」一律给出可操作判据（多大算大、什么方向、何时会误导）。

**趋势状态**：拟合曲线上叠了一条合成基准的**趋势状态色带**（上升/下降/震荡）与
拐头标记，回看窗口可选 1/2/3/5/10/20 个交易日。这是**形态描述**——
用高低点结构回答"这一段长什么样"，`docs/研究方案.md` §4b 记录了它的判据与
三条实测结论（判据非噪声，但时间尺度只有 3~7 天，需放大才可读）。

> Web 版**不输出买卖建议**，只回答「这只基金暴露在哪些风格上、哪个模型拟合最好、风格有没有漂移」。
> 日频择时信号已被本项目的 14 只基金样本外检验证伪，理由见 `docs/研究方案.md`。

## 十一种模型

分四类，**排名只看样本外 R²**（用上一窗口拟合好的模型去预测下一段）：

| 流派 | 模型 | 权重可否当持仓 |
|---|---|---|
| linear | 非负弹性网 + 约束精修 | ✅ 可解释 |
| linear | 非负 Lasso | ✅ |
| linear | 非负 Ridge | ✅ |
| linear | 相关性 Top-K + 约束回归 | ✅ 基准线 |
| linear | 主成分回归 PCR | ✅ |
| linear | 指数加权约束回归 EWMA | ✅ 风格漂移快时占优 |
| linear | Huber 稳健约束回归 | ✅ 抗异常日 |
| tree | 梯度提升树 / 随机森林 | ❌ 仅重要性 |
| kernel | 核岭回归 RBF | ❌ |
| nn | 多层感知机 | ❌ 过拟合对照组 |

线性类权重满足 `w≥0, Σw=90%`，可直接理解为可买组合；黑箱类权重只是重要性排序。
页面会同时显示**窗口内 R² 与样本外 R² 的差**，差值 >0.08 即提示过拟合。

## 方法总览

```
基金净值 ──┐
           ├─► 对齐 & 覆盖率过滤 ──► 滚动 RBSA ──► 合成基准 S_t
候选指数池 ─┘                       │
   (47 个)                          ├─► 风格暴露时序
                                    ▼
                    ┌───────────────┴───────────────┐
                    │  三通道信号                     │
                    │  ① 趋势（作用于 S）             │
                    │  ② 相对偏离（NAV vs S 的价差）   │
                    │  ③ 赛道估值（基准 PE 分位）      │
                    └───────────────┬───────────────┘
                                    ▼
                          综合分 → 目标仓位 → EMA + 死区
                                    ▼
                     无前瞻回测 + 逐方案恒定仓位对照
                                    ▼
              有效样本量 / 共同因子 / 块 bootstrap 稳健性检验
```

### 四个关键设计

1. **两阶段约束回归**：非负 ElasticNet 筛稀疏支撑集 → SLSQP 求解
   `min‖Xw−y‖² s.t. w≥0, Σw=γ`。兼顾稀疏性、可解释性与经济含义。

   ★ **γ 不再固定 0.90，而是逐窗口估计实际股票仓位**（beta 不动点 + 邻域细搜，
   只用窗口内数据）。这不是精度微调 —— 合成收益 `s = γ·u` 与基金收益 `y = γ·u + ε`
   之间的**尺度差会平方进 SSE**，固定 0.9 曾让 4/14 只基金的窗口 R² 归零。
   修复后样本外 R² 中位 0.77 → 0.84，隐含 beta 0.71 → 1.03。详见 `docs/研究方案.md` §2.1.6。

2. **三重无前瞻保障**：RBSA 滚动重估 → 信号只用历史 → 仓位滞后一期生效。

3. **恒定仓位对照组**（最重要）：择时策略平均仓位往往只有 45% 左右，
   直接与「买入持有」比较会把「仓位降低」误认为「择时能力」。
   必须与「同平均仓位的恒定持仓」比较才能分离真实贡献。

   ★★ 并且**每个被测方案都必须配一份自己的对照**（仓位 = 该方案的时间平均仓位）。
   对照组只在「平均仓位一致」时才成立。若拿主策略（平均 43%）的对照去减一个
   平均 100% 的方案，得到的"超额"纯粹是仓位差——实测会让"买入持有"凭空
   多出十几个百分点的表观超额。回测返回的 `controls` / `timing_contrib_all`
   就是逐方案的对照名与净贡献；`timing_contrib` / `control_name` 只对应主策略。

4. **净贡献必须用信息比率口径**（`超额夏普 = 年化超额 / 年化超额波动`）：
   - **夏普不可加** —— `perf_metrics` 的年化是几何年化，
     两个几何夏普相减 ≠ 超额序列的夏普（实测同一份数据差 3 倍以上）；
   - 分子**不扣无风险利率** —— 超额已是相对基准的收益，
     再扣 rf 会把"零超额"算成负值（实测 14 只基金均值从 −0.19 被拉到 −0.88）。

### 稳健性检验：跨基金一致性 ≠ 证据

`python run_robustness.py`

14 只基金的样本外区间**完全重叠**、都是 A 股主动权益基金，横截面并不独立。
本项目实测（250 日窗口 + 季度再平衡那个"100% 基金为正"的候选）：

| 指标 | 值 |
|---|---|
| 平均两两相关系数 | **+0.596** |
| 第一主成分解释方差 | **63.3%** |
| **有效独立样本量 n_eff** | **2.30**（不是 14） |
| 移动块 bootstrap **p 值** | **0.147**（不显著） |
| NW t 值显著 | **1 / 14** |

**任何"N 只基金里 M 只为正"的结论，都应该先跑这个脚本，
确认这 N 只相当于几个独立观测。**

### 多模型横向对比的公平性保证

十一种模型共用**同一份滚动切分**（同一组 `rebal_idx`、同一批窗口），因此排名可比。
两个必须守住的口径：

- **只看样本外 R²**。窗口内 R² 高只是训练集拟合得好；黑箱模型常常窗口内 0.95+、
  样本外掉到 0.7，这就是过拟合。差值 >0.08 会在页面上标黄。
- **黑箱模型的样本外收益来自真实预测**（用上一窗口拟合的估计器前向预测），
  而不是把重要性权重凑成线性组合——后者会让黑箱模型看起来比实际好很多。

性能上，滚动重估点可均匀抽稀（默认 60 个）。抽稀对模型**公平性无影响**
（切分仍然一致），实测 R² 甚至略升，却把 11 模型耗时从 300s 压到 76s。

## 主要实验结论

> 下表为**最新口径**的数字：对照组逐方案构造（仓位已中性化）、
> 净贡献用**超额序列的信息比率**（夏普不可加，且不扣无风险利率）、
> 估值通道计入 10 日发布滞后、Σw 逐窗口自适应估计实际股票仓位。
> 完整推导见 `docs/研究方案.md`。

> ⚠ **下表是旧口径（收益未修正 + 缺陷未修复）的结果，保留作历史对照。**
> 2026-10-12 重算后：E3 正贡献 **50.9%**（非 37.0%）、E6/E7 的显著性**消失**
> （健康门控 p 0.029 → 0.432）、E10 健康门控场内超额 **+0.03%**（非 +0.42%），
> 且新增了 E9b 时间向前验证（迁移 IR −0.23）与 P2-02 增量分析（受约束回归
> 不优于单一宽基）两条否证。最新结论见本文件顶部的修正段与
> `docs/结论快照_口径修正前.md` §3.2。

| 实验 | 旧口径结论（已被重算部分推翻） |
|---|---|
| **拟合质量** | 样本外 R² 中位 **0.84**，14/14 只基金可用 |
| **E0 基准**（14 只） | 超额夏普 > 0 仅 **2/14**，均值 **−0.356**；综合分 RankIC 所有前瞻期均为负 |
| **E1 IC 期限结构** | 趋势通道仅 120 日为正（+0.072）；偏离与估值通道**全期为负** |
| **E2 通道消融** | 六个方案**全部负超额**；「相对偏离」最差（−0.560），确认剔除 |
| **E3 参数敏感性** | 108 组参数中正贡献 **37.0%**（新口径 **50.9%**） |
| **E4 周期匹配** | 250 日窗口 + 120 日再平衡 **+0.352**、**100% 基金为正** |
| **E5 网格最优值** | 最优参数下 14 只全部为正（+0.216~+0.789），固定参数下 2/14 为正 |
| **E6 拟合健康门控** | 旧口径净贡献 IR 均值 +0.101；新口径下**不再显著** |
| **E7 稳健性检验** | 旧口径 n_eff 8.80 / p=0.029 ✅；新口径 **8.99 / p=0.432 ❌** |
| **E8 波动率目标** | 顺波动 −1.32%、逆波动 +0.36%；**风险平价假设不成立** |
| **E9 分折验证** | 旧口径过拟合代价 +0.031；新口径**时间维度**迁移 IR −0.23（E9b） |
| **E10 成本敏感性** | 旧口径健康门控场内 +0.42%/年；新口径 **+0.03%/年，无正贡献档位** |

**新口径下的结论（2026-10-12）**：日频方向择时无效；250 日线索在横截面上
成立但**时间维度不成立**（E9b 迁移 IR −0.23）；三条策略经多重比较校正后
**全部不显著**；风格画像**不优于单一宽基**（仅 3/14 有 >0.05 增量）。
当前功效 6.5%~55.2%，"不显著"更多是**缺乏功效**而非"有效应不存在"——
这两件事必须分开陈述（见顶部修正段第 2/4 点）。

> **方法论提醒**：本项目最硬的教训不是某个策略的成败，而是
> **「跨基金一致性」不等于证据**。任何"N 只基金里 M 只为正"的结论，
> 都必须先回答"这 N 只相当于几个独立观测"——
> `run_robustness.py` 和 `run_walkforward.py` 就是干这个的，
> 建议在采纳任何结论前先跑它们。

## 免责声明

本项目为量化研究方法演示，所有输出仅供研究参考，**不构成任何投资建议**。
Web 界面刻意不提供买卖信号，只做风格穿透与模型对比——
理由见上方 E0~E7：日频择时与拟合健康门控均已被样本外检验证伪，输出建议会误导使用者。

「买卖决策回测」区块仅作为**诊断工具**存在：它用于检验"拟合诊断能否驱动交易"
这一假设，结论是否定的。若该区块显示"零交易"，说明门控判断为全程持有
（或拟合不可信而停用），此时该方案 ≡ 买入持有，绩效差异只来自仓位水平。

回测按单边 0.15% 计提交易成本，对场外基金申赎（申购 1.5% / 赎回 0.5%）而言严重偏乐观，
本框架实际只适用于场内 ETF / LOF 或 C 类份额。
