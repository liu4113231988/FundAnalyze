# 模块与入口

当前名称：`market_research`（Python 包）、`market-research`（发行包及 Web 命令）、“市场研究工作台”（页面）。

## 服务入口

| 命令 | 实现 |
| --- | --- |
| uv run market-research --port 8877 | market_research.api.app:main |
| uv run market-research-worker | market_research.tasks.worker:main |
| uv run market-research-sync --once | market_research.tasks.sync:main |
| uv run market-research-cli COMMAND | market_research.cli.main:main |

## 数据与模型边界

- data.http：超时、重试和基础序列清洗。
- data.providers：基金净值、指数及估值数据源。
- data.cache：缓存版本、元信息、旧 CSV 导入和 DuckDB 写入。
- data.panels：缓存数据集加载、基金/指数对齐和分析窗口。
- data.storage：DuckDB 事务、文件锁、数据指纹与统计。
- modeling.catalog：模型规格、默认参数和界面目录。
- modeling.estimators：单窗口拟合器、约束求解与股票仓位估计。
- modeling.engine：滚动样本外评估、进程池和模型报告。
- data.marketdata / modeling.models：稳定导入门面；具体实现已分离。
- serialization：股票、基金和任务结果共用的有限数值 JSON 转换。

## 路径与兼容

`FIL_HOME` / `FIL_DATA_DIR` 决定运行目录，模块移动不会更改现有行情库与队列。静态文件从安装包资源定位，SQL 从 data/migrations 定位，不依赖当前目录推算。

`src.*` 和 `webapp.*` 为兼容转发，指向同一模块对象，避免配置/任务单例重复初始化；旧 pickle 中的类路径仍可解析。这些兼容模块随 wheel 打包，新代码禁止依赖旧路径。根目录14个脚本用于源码工作区兼容，安装包提供命令入口。

Windows 每日任务名为 `MarketResearch-DailySync`，调用 `.venv/Scripts/pythonw.exe -m market_research.tasks.sync --once --time 18:30`。安装脚本成功注册新任务后，只清理属于当前工作区的旧任务注册。

验证重点：所有旧入口 --help、无副作用导入、旧类路径解析、独立 worker、多进程模型池、SQL/静态资源打包，以及从工作区外使用安装包。
