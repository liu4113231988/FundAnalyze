## 1. 为什么要预注册

当前基金列表是人工固定的便利样本，存在三类偏差：

- **存续偏差**：只含活到今天的基金，清盘/合并的基金自动消失；
- **选择偏差**：列表由人挑选，可能无意中偏向"风格鲜明、拟合得好"的基金；
- **同源暴露**：同一管理人多只基金共享投研平台，横截面相关里有一部分是机械相关。

简单扩到约 200 只**不能**保证得到独立证据 —— 200 只高度相关的基金，
有效样本量可能仍是几个。所以规则要针对"独立性"而不是"数量"。

## 2. 纳入规则（在拉取任何数据之前确定）

| 维度 | 规则 |
|---|---|
| 类型 | 主动权益类（普通股票型、偏股混合、灵活配置中权益仓位 ≥ 60%）；指数基金、ETF 联接、FOF、QDII 除外 |
| 成立时间 | 分层抽样：2015 前成立 / 2015–2019 / 2020 后各占约 1/3，避免全部是同一批老基金 |
| 存续状态 | **必须包含已清盘/已合并基金**（用清盘日的完整历史），否则存续偏差无法消除 |
| 规模 | 取成立满 2 年时规模 ≥ 2 亿元；规模过小会以流动性噪声污染拟合 |
| 管理人 | 单家管理人纳入不超过 3 只（超过则按规模取前 3），直接压低同源暴露 |
| A/C 份额 | 同一组合只保留 A 类（或成立更早的一类），避免同一策略被计两次 |
| 投资范围 | 剔除主题/行业基金（其"风格"由契约决定，不是 RBSA 要解释的对象） |

## 3. 排除记录（必须留痕）

每次排除都要记录 **代码 + 原因 + 判定依据的日期**。不得静默丢弃样本 ——
"筛完之后剩下多少只、为什么少"本身就是结果的一部分。

## 4. 指数与分类的时点可得性

- 逐期只使用**当时可得**的指数与行业分类；新指数上线前的历史不得回填。
- 回填的历史必须打标记，报告中单独列出"含回填历史的样本占比"。
- 指数停编/改名要记录，否则样本后期的候选池与前期不是同一个东西。

## 5. 报告要求

按三个维度**分别**报告覆盖率、效应量与不确定性，不得只给一个总数：

1. **按基金**：n_eff、bootstrap p、NW t 的分布（不是只有均值）；
2. **按管理人**：把每家管理人当成"一份证据"重新聚合；
3. **按市场阶段**：上涨 / 下跌 / 震荡分别报告，检验结论是否只存在于某一个阶段。

## 6. 完成判据

- 纳入规则在数据拉取之前已冻结（本文档的提交时间早于第一次扩池运行）；
- 排除清单可逐条复核；
- 三个维度的报告齐全，且效应量的置信区间与 n_eff 同时给出；
