## 3. 本轮已修正、但**尚未重算**的缺陷

下列缺陷已在本轮修复代码，但它们会改变历史输出，因此上表数字均**未包含**这些修复
（即：上表是"修复前 + 旧口径"的快照，不是"修复后"的结果）：

- **P0-02** 恒定仓位对照键碰撞（50.1% / 50.4% 共用对照，产生虚假超额）
- **P0-04** `vol_target_channel` / `eval_config` / `lowfreq_grid` 的 `bfill()` 未来回填
- **P0-05** 负 R² 被截断为 0、`_constrained_fit` 与黑箱失败静默降级
- **P1-04** 胜率分母含无效前瞻标签、最大回撤漏计首日亏损
- **P1-10** `robustness.py` 的"两个几何夏普相减"诊断改为 IR 口径

重算时必须同时考虑这两类变化（口径修正 + 缺陷修复），并在报告中分别说明。
