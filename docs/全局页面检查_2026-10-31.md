# 全局页面检查 · 2026-10-31

检查覆盖股票、指数、基金、数据中心、共用日期/下拉控件及相关 API。保留检查开始前的工作区改动，在其基础上修复下列问题。

## 本轮已修复

| 范围 | 原问题 | 修复后的行为 |
| --- | --- | --- |
| 基金回测 | 切换证券或页面后，旧回测的状态、错误及结果仍可更新界面 | 提交、轮询和结果读取均检查请求代次；旧响应不能修改新页面 |
| 基金任务 | 分析、重学和回测共用进度条，但按钮禁用不一致；新分析还保留旧回测图 | 共用忙碌状态；新结果清除旧回测，切换页面恢复可操作状态 |
| 模型选择 | 切回基金页会再次应用结果，重置手动模型及最佳模型；设置最佳模型后顶部指标不刷新 | 切页只恢复可见状态和图表尺寸；顶部指标随手动最佳模型更新 |
| 回测口径 | 回测重新使用默认五年窗口、默认参数和精度，与当前分析不一致 | 请求传递已应用的拟合窗口、该模型参数及重估精度；仓位默认值读取分析结果而非尚未应用的控件 |
| 日期边界 | 回测展示区间错误套用两年拟合下限；市场页提交不足 30 天才由后端报错 | 拟合仍需两年，回测展示区间单独校验，计算层要求预热后至少 60 个交易日；市场页提前拦截不足 30 天；基金反向日期明确提示 |
| 参数契约 | MLP 隐藏层数组被后端拒绝；未知参数、负计数、小数计数等可能进入计算 | 按公开模型目录验证参数名、有限值、整数、比例及隐藏层；前端拦截空数值和非法层宽 |
| 核岭回归 | 页面公开的 alpha 参数未被估计器读取，调参无效 | alpha 用于正则候选值；结果缓存版本升至 8，避免复用旧结果 |
| 重学失败 | 请求成功前就写入本地参数，失败后仍可能污染下次分析 | 参数只随成功分析结果更新；已应用参数与调参表单保持一致 |
| 滚动相关性 | 新结果使用默认相关窗口，但选择框可能保留旧值；失败或切页后选择框与图表不同步 | 新结果读取实际相关窗口；失败或切页恢复已展示窗口，丢弃过期响应 |
| 市场任务 | 点击当前入口会废弃正在运行的请求；排队较久时约 126 秒就被前端宣告失败 | 当前入口重复点击不重置状态；等待后端任务终态；统一禁用运行相关按钮，执行中改设置保留未应用提示 |
| 数据中心 | 添加/重试发生在旧刷新期间时，新刷新被 busy 标志丢弃；自动恢复后旧错误仍显示 | 合并刷新请求并在当前请求后补读一次；成功恢复清理读取错误；添加后按提交时的类型筛选，指数提交空口径 |
| 页面提示 | 股票、指数示例框的 title 仍叫“示例基金”；基金名录的晚到提示可出现在其他页面 | 示例 title 与入口一致；名录提示检查请求代次及当前证券 |

## 本轮验证

- 73 项 Python unittest 全部通过，包含新增 5 项页面参数、窗口传递及核岭回归参数效果检查。
- 两套独立数值回归通过：`test_p0_fixes.py`、`test_regressions.py`。
- 两套前端回归通过，增加旧回测错误、晚到结果的隔离用例。
- 4 套 Edge 浏览器检查通过：基金、共用控件、数据中心、全局页面契约。
- 浏览器检查覆盖桌面和 390px 手机宽度、空/加载/失败状态、日期输入、键盘与弹层、页面切换、模型选择、回测配置和数据中心并发刷新。
- JavaScript 语法检查和 `git diff --check` 通过。

浏览器使用独立无界面 Edge 配置。分析请求采用本地可信结果及受控响应；数据中心读取本机资产，添加/重试请求被拦截。未重抓全部行情、完整重跑全部基金模型，未进行跨浏览器或负载测试。本轮没有修改真实资产名单或提交浏览器测试计算任务。

## 仍需后续完善

- 数据中心名称来自静态目录，自定义证券不一定能按名称搜索；代码搜索可用，需要接入完整证券名称源。
- 刷新浏览器后还不能自动恢复研究视图；后台任务持久化与前端恢复是两件事。
- 交易日历、停牌识别、历史行情版本和基金实际申赎费用仍属原有能力缺口，详见[功能完整性检查](功能完整性检查.md)。

缓存版本变化会使已有基金结果缓存失效，下次分析可能需要重算；原始行情缓存不因此失效。
